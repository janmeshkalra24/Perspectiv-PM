# Vite React TypeScript Starter

A modern web application starter using Vite, React, TypeScript, and TailwindCSS.

## Prerequisites

- Node.js (version 18.0.0 or higher)
- npm (version 8.0.0 or higher)

To check your versions:

```bash
node -v
npm -v
```

## Installation

2. Install dependencies:

```bash
npm install
npm install vite --save-dev
```

3. Build the project:

```bash
npx vite build
```

4. Start the server:

```bash
npm vite preview
```

This will start the server at `http://localhost:4173` (default port)
